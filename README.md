# PROJECT: IRON MAN — REAL-TIME AI POWER SUIT (MARK LXXXV)

A real-time Augmented Reality (AR) Iron Man Power Suit experience powered by **MediaPipe Vision Tasks (`PoseLandmarker`, `FaceLandmarker`, `HandLandmarker`)**, **Three.js Physically Based Rendering (PBR)**, **Custom GLSL Shaders**, **Web Speech API**, and **Web Audio API Procedural Sound Synthesis**.

## Quick Start
Open `index.html` or run `npm install && npm run dev` in Google Chrome or Microsoft Edge and click **Start Camera** & **Enable Microphone**.

## Features Implemented
1. **Live Camera & Full Body Tracking**: Real-time 33-point Pose, 478-point Face/Iris, and 2x21-point Hand tracking with velocity smoothing and body calibration.
2. 2. **Complete 3D PBR Mechanical Armor**: Articulated Helmet with motorized hinged Faceplate (revealing your real face when opened), glowing Arc Reactor, layered Chest Plastron, Pauldrons, Bicep cylinders, Gauntlets, Palm Repulsors, Segmented Abdomen, Thigh Cuisses, Knee Guards, Calf Greaves, and Thruster Boots.
   3. 3. **Finger Snap 10-Stage Suit Assembly**: Dual-modal finger snap detector (hand landmark thumb-middle snap kinematics + microphone high-frequency transient detector).
      4. 4. **Voice Control (English & Hindi)**: Full Web Speech API command pipeline with synthesized J.A.R.V.I.S. confirmations.
         5. 5. **Interactive Weapons & Flight Systems**: Palm-tracked Repulsor charge/fire beams, head/gaze-tracked Eye Lasers, Fist-activated Hexagonal GLSL Force Field Shield, and Flight Mode with boot/palm plasma thrusters.
